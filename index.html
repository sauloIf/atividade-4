O HTMl é uma linguagem de marcação usada para estabelecer e apresentar o conteúdo.

Ele foi criado em 1991 por Tim Berners-Lee, e desde então tem evoluido constantemente. Atualmente, é fundamental para a criação de sites e aplicativos modernos.

O uso de tags é essencial para formatar o conteúdo textual corretamente.
